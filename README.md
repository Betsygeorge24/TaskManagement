# Task Management MERN App

## Overview
A full-stack task management application built with MongoDB, Express.js, React.js, and Node.js.

## Backend Setup
1. `cd backend`
2. `npm install`
3. Create `.env` with:
   - `MONGO_URI=mongodb://127.0.0.1:27017/taskmanagement`
   - `JWT_SECRET=your_secret`
4. `npm run dev`

## Frontend Setup
1. `cd frontend`
2. `npm install`
3. `npm run dev`

## Features
- User registration and login
- Task CRUD operations
- Task assignment to users
- Status tracking
- Dashboard UI
